# Titian

CLI bergaya vendor (Cisco/Junos) di atas klish + BIRD untuk router
**FreeBSD/BSDRP** — bukan Debian/Linux.

- **Branch `bsdrp`**: patch + file Titian untuk image BSDRP resmi, paket
  `titian` 0.1.1 (rilis 24 Nov 2026). Baca `README.md` di branch itu.
- **Branch `titian-api`**: `bsdrp` + API HTTP+JSON (94 endpoint v1) +
  web UI operator untuk BRAS. Calon rilis 0.1.2, belum dirilis.
- Branch `main` ini berisi dokumen lab — kerja aktif Titian ada di
  `bsdrp` dan `titian-api`.
